You Don't Need Cursor — you need to understand the loop

An offline, interactive tutorial where you build a coding agent harness by running one, checkpoint by checkpoint, from "no tools, pure hallucination" to a real read-think-write loop with an approval gate.

🔌 zero network requests 📦 zero dependencies 🔑 no API key needed 🕵️ zero telemetry

Checkpoint 0 — Hello, Loop

The dumbest possible harness: one message in, one message out. No tools, no memory of your files, no eyes. This is what "AI in a chat box" actually is — and it's the thing every real coding agent starts as, before anyone adds the parts that matter.

The whole harness

That's it. No file access, no loop, no tools. Whatever it says, it's guessing.

        How this maps to the real thing
        
    
        
      Cursor, Claude Code, Aider, Copilot Workspace — under the fancy UI, they're all running some version of Checkpoint 3:
      a loop that sends messages to a model, lets it call tools, keeps going until it says it's done or the leash runs out,
      and enforces some policy about which actions need a human. The model provider, the sandboxing, the diffing, the context
      management — all real engineering. But the shape of the loop is exactly what you just ran, by hand, in your browser.
    
        
    
        
      This page's "model" is a fixed script, not a real LLM — there's no API key field anywhere because there's nothing to
      call. Swap the mockModel-shaped pieces in the source for a real API request (see the
      <script> tag — it's all right there, this is a single HTML file) and the harness code
      around it barely changes. That's the whole point: the loop is the product. The model is a swappable part.
    
        
    
        No network requests. No telemetry. No accounts. Open your browser's Network tab while you use this page — it'll stay empty.
